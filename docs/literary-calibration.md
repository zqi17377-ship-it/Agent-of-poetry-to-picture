# 文学理解校准：阿多尼斯偏好

用户偏好现代外国诗文，特别是阿多尼斯及《我的孤独是一座花园》。该书为薛庆国翻译、译林出版社出版的诗选集，不能把书名当作整本诗文的内容。书目信息见[出版社提供的电子书介绍](https://read.douban.com/ebook/35612072/)。

本次改进是提示词、创作案例和回归测试校准，**没有训练或微调模型权重**。没有下载整本诗集，也没有把未核实的网络摘句标为阿多尼斯原作。用户输入的文字作为待解释材料处理，不推断出处及唯一作者意图。

## 从诗到画面的规则

1. 阅读整个段落，提取最重要的具体物象、动作及关系；引用必须是原文的连续子串。
2. 隐喻的抽象含义通过空间、距离、光线与材质表达，但具体物象仍需可见。例如羽毛与台阶不应被替换成普通草地。
3. 每个提取的意象都要有“原文引用 → 可见画面元素 → 文学联系”。遗漏引用或虚构引用时停止出图；这些画面元素直接写入图像提示词。
4. 选择一个连贯场景。可以是近景、静物、建筑空间或风景，避免把一切文本都套成阴天湖岸。
5. 偏冷色只是默认偏好，文本的温暖、生命感或复杂情绪优先。孤独可以是私密空间中的生长，不一定是荒凉或悲伤。
6. 解释保留歧义，场景、光线及色彩的创作补充单独列出。最终是否贴合原文由用户看图判断。

提示词中的纸船、窗上晨光示例及脚本中的花园段落为开发者自编校准材料，不是诗人作品。书名的花园/孤独关系是一个可能的创作阅读，不代表作者的确定意图。

## 复现实测

先运行 `安装文学模型.cmd`，然后：

```powershell
.\.venv\Scripts\python.exe scripts/check_literature.py
```

脚本只调用本机 Qwen，检查用户提供的失败用例和两个自编段落，不请求图片。结果保存在忽略的 `data/local-literature-check.json`。结构化引用校验无法证明模型提取了所有重要意象，也无法证明出图模型实际呈现了所有物象；仍需人工核对。
