# 开发与验收记录

## 2026-10-11 文学语义修正（当前版本）

复现用户反馈：旧关键词模式无法识别“时光之羽、永恒之台阶”，提取意象为空，随后默认生成无关草地。修正从语义理解到图像提示词的链路：

- 默认使用本机 Qwen3-4B Q4_K_M，免费 CPU 文学理解，保留可独立替换的文字/图像 API。
- 原文引用、隐喻歧义、情绪与动作关系单独保存；每个提取的意象对应一个可见画面元素，加入图像提示词。遗漏或虚构引用、空意象、截断输出会停止出图。
- 取消“一切都是风景”的预设，允许近景、静物和建筑空间。英文画面字段通过结构化约束，中文解释保留在界面。
- 阿多尼斯偏好通过[创作校准规则](literary-calibration.md)落实，不声称训练模型权重或理解整本诗选。
- 官方模型与 Windows 运行程序固定版本、SHA256 校验，首次安装约 2.5GB。本机服务随机端口、临时认证、隐藏运行；只停止应用创建的子进程。

实际本机测试：自编晨光/热茶段落完成理解与构图约 101.5 秒，保留窗、晨光、长夜修复与茶的联系，使用暖色调，画面字段英文、解释中文。两个原文意象均进入实际图像提示词。只测理解时没有请求图片。固定 Windows CPU 运行版本为 llama.cpp b10025。

网页真实出图验证：将用户反馈中的“我如何用时光之羽，刻画在永恒之台阶上，爬上爬下的细节吗？”重新生成，得到版本 `2541991baa2c4e75a4f9f74180cbddbb`。人工查看结果：冷色建筑空间中出现羽毛和向上延伸的台阶，与旧版本的无关草地相比，两个核心物象得到保留。页面可展开查看原文引用、中文解释和英文画面元素，旧作品仍保留。

这次结果仍有明确限制：“爬上爬下”的动作未充分提取和表现，羽毛的象征也采用了其中一种解读。单次成功不能证明完全理解诗歌；自然程度和意境是否合意需要用户判断。未启用自动视觉评分，也没有使用整本诗选进行权重训练。

最终验证：后端 **38 个测试通过**，前端 **3 个任务同步回归测试通过**，TypeScript/Vite 生产构建通过。下面保留首版记录用于说明变化。

## 功能验证与限制

后端测试覆盖：输入边界、原文引用校验、结构化理解失败、适配器请求/响应、密钥不泄漏、超时不重试、任务重启、排队领取、版本关联、租约、下载、跨站请求拒绝和评估失败保留图片。前端需要通过 TypeScript/Vite 构建，并进行浏览器操作检查。

前端回归测试覆盖任务已快速完成时加载新版本、完成作品临时读取失败后整组重试、活动任务保持真实阶段。修复在请求完成前切换作品时的状态覆盖；意外异常日志只记录任务编号和异常类型，避免原始服务商响应或密钥泄漏。

免费模式的基础理解并非语言模型；复杂隐喻、否定和时间关系可能丢失。首页和模型设置说明这一限制。对外国文学的深入理解需要接入语言模型后继续调试。

参考图编辑、方形/竖幅真实出图、12 个样本的用户审美评分和实际 token/费用统计尚未完成。`eval/samples.json` 为自编回归材料；它们不是外国诗歌原作，也不是已评分的验收结果。自动视觉质检尚未启用。视频待图片效果确认后开发。

## 与原始计划的调整

- 不等待创建收费账号：免费图片模型配合基础理解，让用户先试操作和出图；后续文字与图片 API 可分别更换。
- worker 放在后端进程生命周期内，通过 SQLite 租约防止重复实例处理，保留持久化排队和重启保护。
- 不执行任何自动重试，包括可判断未提交的连接错误；用户明确触发下一次请求。
- 图像适配器返回字节，仓库统一验证/保存文件；任务、版本和租约事务集中在 Repository。
- 审美验收保留人工评分，不把未完成的 12 样本实验标为完成。

原始计划保留为设计基线；以上记录说明当前实际交付范围。
