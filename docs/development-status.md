## 功能验证与限制

后端测试覆盖：输入边界、原文引用校验、结构化理解失败、适配器请求/响应、密钥不泄漏、超时不重试、任务重启、排队领取、版本关联、租约、下载、跨站请求拒绝和评估失败保留图片。前端需要通过 TypeScript/Vite 构建，并进行浏览器操作检查。

前端回归测试覆盖任务已快速完成时加载新版本、完成作品临时读取失败后整组重试、活动任务保持真实阶段。修复在请求完成前切换作品时的状态覆盖；意外异常日志只记录任务编号和异常类型，避免原始服务商响应或密钥泄漏。

免费模式的基础理解并非语言模型；复杂隐喻、否定和时间关系可能丢失。首页和模型设置说明这一限制。对外国文学的深入理解需要接入语言模型后继续调试。

参考图编辑、方形/竖幅真实出图、12 个样本的用户审美评分和实际 token/费用统计尚未完成。`eval/samples.json` 为自编回归材料；它们不是外国诗歌原作，也不是已评分的验收结果。自动视觉质检尚未启用。视频待图片效果确认后开发。

## 与原始计划的调整

- 不等待创建收费账号：免费图片模型配合基础理解，让用户先试操作和出图；后续文字与图片 API 可分别更换。
- worker 放在后端进程生命周期内，通过 SQLite 租约防止重复实例处理，保留持久化排队和重启保护。
- 不执行任何自动重试，包括可判断未提交的连接错误；用户明确触发下一次请求。
- 图像适配器返回字节，仓库统一验证/保存文件；任务、版本和租约事务集中在 Repository。
- 审美验收保留人工评分，不把未完成的 12 样本实验标为完成。

原始计划保留为设计基线；以上记录说明当前实际交付范围。

GitHub 按“需求与计划 → 后端工作流 → 界面与交付”分阶段记录。本机 Git 提交已创建；由于本机 Git 推送未配置凭据，使用已授权 GitHub 连接器发布这些源码快照，服务端提交 SHA 与原本本机提交可能不同。没有上传 API 密钥、本机作品或依赖目录。
